What I've built

Flagship Project

CineMatch

Hybrid AI Movie Recommendation Engine

Most recommendation systems pick one approach. CineMatch uses two: a SBERT semantic similarity model handles 60% of the scoring to understand the intent behind a query ("films like Arrival but grounded in science"), while a TF-IDF content engine covers the remaining 40% for metadata precision. The blend was tuned empirically against TMDB data until results felt natural rather than just statistically correct.

SBERT + TF-IDF Hybrid ranking engine
60 / 40 Semantic vs content weight
TMDB Real movie metadata source

Flutter Web frontend with real-time autocomplete search. Firebase Authentication and Realtime Database for user sessions. FastAPI backend serves the model.

Flagship Project

FinanceAI

Intelligent Stock Analysis Platform

FinanceAI layers three independent signals into one platform: an LSTM neural network forecasts 7-day price movement with a ~2.45% mean absolute percentage error; a Z-Score anomaly detector flags statistically unusual market behaviour (useful for spotting pre-crash signals); and a LLaMA 4 model with a RAG pipeline synthesises news and financials into a readable investment report. Each signal can be used alone or together. Works across US, Indian, UK, German, Japanese markets and crypto.

~2.45% LSTM forecast MAPE
Z-Score Anomaly detection method
LLaMA 4 + RAG LLM investment reports
5+ markets US, IN, UK, DE, JP, Crypto

Flutter Web frontend, FastAPI backend on Render. Firebase Auth + Firestore for user data. TensorFlow for the LSTM. LangChain orchestrates the RAG pipeline.
